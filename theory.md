Virtual Reality (VR) is a simulated experience that immerses users in a digital environment using specialized hardware such as headsets and controllers. This experiment covers three main aspects of VR technology: <br><br>

1.	<b>VR Hardware Interaction </b>– Understanding and using the Meta Quest 3 VR headset and controllers. <br>
2.	<b>VR Development Components </b> – Exploring 3D modeling, game engines like Unity, and XR technologies that power VR applications. <br>
3.	<b>VR Interaction and Environment Control </b> – Learning how to manipulate virtual lighting and interact with digital objects using controllers. <br><br>

Through these tasks, participants will develop an understanding of VR fundamentals, including user interaction, physics simulation, and content creation. <br><br>
